DATA / POSTGRESQL

Thinking about PostgreSQL beyond CRUD.

A practical note from my ongoing journey of building and understanding backend systems.

Model for the domain

Tables and relationships should reflect the business concepts the application needs to protect.

Indexes have a purpose

An index should support a real access pattern. Understand the query before adding an index.

Transactions protect invariants

When several writes must succeed together, a transaction provides a clear consistency boundary.

Observe the query

For performance work, inspect the actual query plan and workload rather than optimizing from intuition.
